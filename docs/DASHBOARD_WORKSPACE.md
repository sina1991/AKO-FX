# منوی راست‌کلیک و اسلات‌ها — نسخه 0.3

الگوی تعامل از اسلات‌های پروژه مرجع 30nA گرفته شده و با بخش‌های AKO-FX سازگار شده است. منو در داشبورد واردشده فعال است؛ روی input، textarea، select و لینک، منوی معمول مرورگر برای انتخاب/کپی/ویرایش حفظ می‌شود.

## بازکردن منو

- روی عنوان یا بدنه اسلات راست‌کلیک کنید.
- با کیبورد اسلات را focus کنید و Shift+F10 یا ContextMenu بزنید.
- روی موبایل از ⋮ استفاده کنید؛ نگه‌داشتن روی فضای غیرورودی نیز منو را باز می‌کند.
- منوی «فضای کاری» در نوار بالا همان گزینه‌های سراسری را در دسترس می‌گذارد.

Arrow Up/Down، Home/End برای منو و Escape برای بستن و بازگرداندن focus هستند. منو در مرز viewport محدود می‌شود و فهرست طولانی داخل خودش scroll دارد.

## گزینه‌های هر اسلات

| گزینه | اثر |
|---|---|
| عملیات همین بخش | همان دکمه‌های مجاز فرم/حساب/پلن/معامله؛ اعتبارسنجی و مجوز API همچنان برقرارند |
| حذف اسلات از چیدمان | اسلات اصلی مخفی و قابل بازیابی می‌شود؛ یادداشت/نمای سفارشی از چیدمان حذف می‌شود |
| رنگ‌بندی | رنگ کادر، زمینه و نوشته، اندازه فونت ۱۲ تا ۲۴ |
| اندازه | عادی، تمام عرض یا فشرده با محتوای scrollable |
| تغییر نام | عنوان نمایشی؛ شناسه واقعی حساب/معامله تغییر نمی‌کند |
| جمع‌کردن | محتوای اسلات جمع می‌شود و عنوان/⋮ باقی می‌ماند |
| Pin | اسلات در ابتدای گروه هم‌سطح خود قرار می‌گیرد |
| قفل چیدمان | تغییر ظاهر/حذف/جابه‌جایی UI تا بازکردن قفل متوقف می‌شود؛ مجوز معامله را تغییر نمی‌دهد |
| جابه‌جایی | جلو/عقب در گروه هم‌سطح؛ Pin اولویت دارد |
| Duplicate نمایشی | نمای خواندنی مستقل از همان داده، با تنظیمات ظاهر جدا؛ حساب یا معامله جدید ایجاد نمی‌شود |
| شناسه مورد / شناسه اسلات | شناسه مالی و شناسه نمایشی از هم مشخص‌اند |
| Terminal / اطلاعات | دستور GET همان API بدون token یا password برای کپی نمایش داده می‌شود |

بازکردن منو هیچ سفارش یا تأیید مالی ارسال نمی‌کند. انتخاب عملیات فرم، از همان کنترل اصلی استفاده می‌کند و در صورت ورودی ناقص، فرم را برای تکمیل نشان می‌دهد. کنترل‌های مالی قابل مشاهده نیز باقی مانده‌اند. اگر اسلات اصلی مخفی باشد، «رفتن به بخش اصلی» آن را موقتاً برای تعامل نشان می‌دهد؛ تنظیم ذخیره‌شده با refresh دوباره اعمال می‌شود.

## یادداشت و چیدمان

«افزودن یادداشت» یک اسلات متن ساده تا ۲۰۰۰ کاراکتر می‌سازد. HTML اجرا نمی‌شود. ویرایش از منوی همان یادداشت انجام می‌شود. تا ۲۴ اسلات سفارشی و پنج چیدمان نام‌دار قابل ذخیره‌اند. چیدمان شامل ظاهر، binding نمایشی و متن یادداشت‌هاست؛ موجودی، حساب، معامله یا credential را کپی نمی‌کند.

ذخیره با نام تکراری همان قالب را به‌روز می‌کند. بارگذاری قالب، چیدمان فعلی را پس از تأیید جایگزین می‌کند. «واگردانی» ده تغییر اخیر همین ورود را در حافظه دارد؛ پس از refresh/خروج، undo history پاک می‌شود، ولی تنظیم ذخیره‌شده روی سرور می‌ماند.

«بازیابی اسلات‌های حذف‌شده» نمایش اسلات اصلی را برمی‌گرداند. «بازنشانی ظاهر همه» یادداشت‌ها را نگه می‌دارد و فقط appearance را پاک می‌کند. حذف خود یادداشت تأیید جدا می‌خواهد. خروج، منو، dialog، متن یادداشت‌ها و داده‌های قبلی صفحه را پاک می‌کند تا کاربر بعدی اطلاعات قبلی را نبیند.

چیدمان برای هر user مستقل است و بین مرورگرها از API همان حساب خوانده می‌شود. هیچ Session token یا credential در آن ذخیره نمی‌شود. اگر دو تب هم‌زمان تغییر دهند، revision قدیمی رد می‌شود؛ صفحه آخرین نسخه را دریافت می‌کند و کاربر می‌تواند تغییر را دوباره انجام دهد.

## محدوده اسلات‌ها

Wallet، ساخت Broker، حساب‌ها، positionها، پلن‌های Prop، درخواست‌های اعتبار، دفترکل و قیمت‌های مصنوعی منو دارند. بخش‌های بررسی Prop، درخواست کاربران و audit فقط برای ادمین ثبت و قابل binding هستند. یک mirror بخش ادمین به user معمولی داده نمی‌شود.

این قابلیت یک سیستم UI برای همان خدمات AKO-FX است؛ Worker، Chat و اجرای کد پروژه مرجع به این مخزن منتقل نشده‌اند. منو گزینه غیرعملی برای سرویس‌های ناموجود نشان نمی‌دهد. نمودار/قیمت‌ها همچنان در محیط دمو هستند و قیمت مصنوعی با refresh به‌روز می‌شود.

## API و CLI

`GET /api/dashboard/layout` شامل revision و layout است. `POST` همان مسیر به Idempotency-Key و body با revision فعلی و layout جدید نیاز دارد. فیلد user_id پذیرفته نمی‌شود؛ owner فقط از Session گرفته می‌شود.

```bash
clear
python3 -m ako_fx.cli GET /api/dashboard/layout
python3 -m ako_fx.cli POST /api/dashboard/layout --data '{"revision":0,"layout":{"items":{"wallet":{"color":"#53e0b0","pinned":true}},"slots":[],"saved":[]}}'
```

مثال POST فقط برای revision صفر است؛ قبل از ویرایش مقدار واقعی GET را بگیرید. برای retry همان درخواست از همان `--key` استفاده کنید. Layout حداکثر ۹۶ KiB و transport این مسیر حداکثر ۱۲۸ KiB است؛ بقیه مسیرهای API سقف قبلی ۱۶ KiB را دارند. رنگ فقط HEX و اندازه/flagها با نوع صریح پذیرفته می‌شوند. قفل چیدمان کنترل دسترسی امنیتی نیست؛ صاحب حساب می‌تواند از CLI تنظیم خودش را تغییر دهد.
